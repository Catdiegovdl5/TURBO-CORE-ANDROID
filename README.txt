🚀 TURBO CORE V111 - FREE FIRE SPECIAL EDITION
--------------------------------------------------
Desenvolvido por: Diego
Versão: Standalone (Tudo em um arquivo só)

Este software otimiza seu Android para performance extrema, 
ajustando DPI, resolução e latência via ADB.

--- 🛠️ PASSO A PASSO PARA CONECTAR ---

1. No seu celular, vá em: Configurações > Sobre o telefone.
2. Clique 7 vezes em "Número da Versão" até liberar o Modo Desenvolvedor.
3. Volte e vá em: Sistema > Opções do Desenvolvedor.
4. ATIVE: "Depuração USB".
5. Conecte o cabo USB no PC e aceite a permissão que aparecer na tela do celular.

--- 🎮 COMO USAR O APP ---

1. Extraia este arquivo ZIP em uma pasta (não execute de dentro do ZIP).
2. Abra o arquivo "TurboCore_V108_Final.exe".
3. Se o Windows der um aviso de "Editor Desconhecido", clique em:
   'Mais informações' > 'Executar assim mesmo'.
4. Quando o status no topo ficar VERDE e aparecer o nome do seu celular, você está pronto.

--- 🎯 MODOS ESPECIAIS (FREE FIRE) ---

• FF SENSI (CAPA): Diminui a DPI para 90. A tela ficará pequena, 
  mas a sensibilidade para subir capa fica absurda. 
• FF LISO (PERFORMANCE): Baixa a resolução para 540p e limpa a RAM. 
  Ideal para rodar sem lag em celulares mais fracos.
• RESTAURAR ORIGINAL: Use este botão para voltar o celular ao normal 
  quando terminar de jogar.

--- ⚠️ DICAS IMPORTANTES ---

- Se o celular desconectar sozinho, o programa tentará reconectar em 5 segundos.
- Use cabos USB de boa qualidade para evitar quedas.
- O programa agora funciona sozinho, você NÃO precisa da pasta 'bin'.
